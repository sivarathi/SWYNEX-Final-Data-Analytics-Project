# SWYNEX Final Data Analytics Project

## Project Overview
A complete data analytics case study based on student performance data, combining data cleaning, exploratory analysis, and an interactive Power BI dashboard.

## Project Workflow
1. Data Cleaning & Preparation
2. Exploratory Data Analysis
3. Interactive Dashboard
4. Key Insights & Findings

## Tools Used
- Python
- Pandas
- Google Colab
- Power BI
- GitHub

## Key Insights
- Attendance has a moderate positive relationship with Exam Score.
- Hours Studied shows a positive relationship with Exam Score.
- Previous Scores show a weak positive relationship with Exam Score.
- Sleep Hours show almost no relationship with Exam Score.
- Higher parental involvement is associated with slightly higher average scores.

## Dashboard
The project includes an interactive Power BI dashboard with KPIs, visualizations, and filters to analyze student performance.

## Project Outcome
This project helped develop practical skills in data cleaning, exploratory data analysis, data visualization, Power BI, and presenting analytical insights.
